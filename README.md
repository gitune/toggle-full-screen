# toggle-full-screen

## これは何？

画面右下にFullscreen Modeへ切り替えるフローティングボタンを表示させるFirefox機能拡張です。

## 使い方

機能拡張をインストールすると、全てのページの右下にFullscreen Modeに切り替えるためのフローティングボタンが表示されます。ボタンをクリック／タップするとFullscreen Modeとなり、もう一度押すと解除されます。ボタンを長押し(ロングタップ)すると消えます。ページをリロードすると復活します。

通常の(PC用の)FirefoxおよびFirefox for Androidで動作することを確認しています。
